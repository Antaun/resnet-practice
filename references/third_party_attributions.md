# Third-party references and licenses

This project contains an adapted ResNet implementation for CIFAR-10 image classification. The architecture and training patterns were inspired by the public Keras example for residual networks.

## Public code used

- Keras team. "ResNet for CIFAR-10".
  - Source: https://keras.io/examples/vision/resnet/
  - License: Apache License 2.0
  - Note: The residual block pattern and training workflow used in this project are based on that public example.

## Dataset reference

- Krizhevsky, Alex. "Learning multiple layers of features from tiny images."
  - Dataset: CIFAR-10
  - Source: https://www.cs.toronto.edu/~kriz/cifar-10-python.tar.gz
  - Note: This dataset is used for educational benchmarking in this project.
